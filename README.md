# Student Management System

A beginner-friendly, console-based Student Management System built using Python. This project allows users to manage student records through a simple menu-driven interface.

## Features

* **Add Student:** Add a student's name, roll number, and branch.
* **View Students:** Display all student records.
* **Search Student:** Find a student using their roll number.
* **Update Student:** Modify a student's name and branch.
* **Delete Student:** Remove a student record with confirmation.
* **Menu-Driven Interface:** Navigate between operations using numbered options.

## Technologies Used

* **Language:** Python
* **Concepts:** Functions, Lists, Dictionaries, Loops, Conditional Statements, and User Input

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Solitudeseeker/Python-Student-Management-System.git
   ```

2. Open the project folder:

   ```bash
   cd Python-Student-Management-System
   ```

3. Run the program:

   ```bash
   python main.py
   ```

## How to Use

After running the program, choose an option from the menu:

```text
===== STUDENT MANAGEMENT =====
1. Add student
2. View Student
3. Search Student
4. Update Student Details
5. Delete Student
6. Exit
```

Enter the number corresponding to the operation you want to perform and follow the prompts.
